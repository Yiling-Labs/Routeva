# design/ — Agent 原则

## 职责

产品**视觉与交互设计产物**：线框、高保真、设计导出。

## 子目录

| 路径 | 用途 |
|---|---|
| `wireframes/` | 线框、低保真流程 |
| `hi-fi/` | 高保真界面、设计系统导出 |

## 原则

1. 设计探索稿放本域；**商店截图终稿、宣发海报**放 `gtm/`。
2. 文件命名可读：`{flow}-{screen}-{variant}.ext` 或团队统一前缀。
3. 大二进制若撑爆 git，改用 LFS 或外链，并在本目录 README（若有）说明。
4. 不在此写业务需求正文（需求在 `docs/` / `PRODUCT.md`）。
5. 本 AGENTS 不规定具体 UI 风格或品牌色——那是产品设计决策，不是结构原则。
