## 产品母题（不变）

视觉源：craft-p0 · Field Black + mint · Soft glass · Instrument Quiet。

## Apple 原则如何落到图标

| 原则 | 本轮怎么用 |
|---|---|
| **Purpose** | 每枚只讲一件事；不做盾/锁/地球（品类滥俗 ≠ 熟悉） |
| **Simplicity** | 剪影优先；29pt 仍可读；一层主 mark |
| **Craft** | 统一顶左 key light；柔和景深；材质可读 |
| **Familiarity** | 隐喻取自物理控件（开关、路径、环、字标），非 VPN 海报 |
| **Materials** | Soft glass / frosted / 实体开关感——对齐 Home soft glass |
| **Delight** | 冷静自信，不是霓虹狂欢 |
