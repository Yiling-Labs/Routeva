# Direction D · Probe Capsule

## 锚点

[Pinterest · Button Idea](https://www.pinterest.com/pin/406872147608295188/) — Jason Sanders  
**严格跟 pin：** soft glass / 双态场域色 + **竖直滑动胶囊**电源控件 + 径向波纹。

## 气质

精致消费级 VPN 控件质感 × Routeva 诚实状态机。  
**可信、冷静**；波纹 = Probe 验证，不是装饰。

## 必含四屏（English）

1. **Home · Idle** — 深炭灰场域；START 胶囊；Swipe up to connect；Active 订阅名；Auto  
2. **Home · Connected (Verified)** — 薄荷绿场域；Verified + Connected；节点 · Auto；STOP + 成功波纹  
3. **Diagnostic · Client-Fixable** — 同体系卡片；四桶标签；原因/影响/下一步/置信度；Repair CTA  
4. **Repair Confirm** — Allowlist 摘要；Confirm / Cancel  

## 明确不做

- Go Premium / 付费墙  
- 国旗条 / Location 当主路径  
- 假绿「一开图标即 Connected」  
- 大世界地图卖点 / 带宽 session 主信息（可极弱装饰）

## form 母题

**滑动胶囊 = 唯一主动作；径向波纹 = Probe；场域色 = 连接真值。**
