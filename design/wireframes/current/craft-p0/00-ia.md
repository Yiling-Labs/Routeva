# Craft P0 — 信息架构与关键流程

> 依据 PRD v0.2 / CONTEXT；**不扩功能**。用户可见文案 **English**。  
> Beta：无付费墙。  
> 视觉方向：**pin glass + vertical capsule**（黑 / 绿双皮肤；**无底部 Tab**）。  
> 权威 hi-fi：Home **`02-home.html`** · Setup `03-setup.html`  
> **MVP 无 Help**（ADR **0063**）。ADR 0018 / 0019 / **0058** / **0059** / **0063**  

## 1. 全局导航（无底部 Tab）

**根画布只有 Home。** 顶栏 = **纯出口**（ADR 0020）。诊断 / 修复为 **modal sheet**。

| 面 | 角色 | 进入方式 | Craft |
|---|---|---|---|
| **Home** | 选节点、连接手势、连接真值 | App 根 | P0 Craft |
| **Subscriptions** | 单列表 + Active | 顶栏（有订阅时） | P0 Craft |
| **Settings** | §1.2 闭集 | 顶栏右 gear | P2 |
| **Activity** | 本机记录 · **无 UI**（0063） | — | 能力 P0 |
| **Location** | 扁平 Preferred · Test | 节点名行 / 绿场节点行 | P0 |
| **Help / Diagnostic / Repair** | **Post-MVP** | 不进 MVP 顶栏 | explore 存档 |

### 1.1 顶栏

| 状态 | 布局 |
|---|---|
| **有订阅** | `[ Subscriptions ] ………… [ Settings ]`（ADR **0063**） |
| **Empty** | `[ Settings ]` only（Add 走中部 CTA） |

soft glass 圆钮；**禁止**底 Tab、顶栏 Help（MVP）、顶栏 Activity。

### 1.2 Settings Surface（根页闭集）

主职：**Connection Policy 优先**。光暗跟系统；无 Appearance / Advanced / Cloud AI 开关 / 付费墙。

| 段 | 根页行 | 二级要点 |
|---|---|---|
| **Connection** | Routing mode › · Overrides › | 每行**释义副文**（解释标题，不绑选项）：Mode *How traffic uses your proxy*；Overrides *Exceptions for specific domains*。二级：Mode **Smart**/Global（与 Home 同闭集；返回时若变更则 `setRoutingMode`）；Overrides Domain only（O3；ADR 0045 / **0057** / **0050**）。**无 DNS 行**；运行时固定 Automatic。 |
| **App** | **Auto-update subscription**（Toggle 默认开）· Subscriptions › · About › | 自动刷新总闸见 ADR **0015**；无根页 Privacy；隐私经 About → Privacy Policy；Subscriptions 深链；Export 在 About 次要 |

**明确不进 Settings 根页：** History/Activity/Snapshots（ADR **0051**）、节点列表、订阅 CRUD 副本、Run Diagnostic 主 CTA、Cloud AI Toggle、Appearance、Advanced、Restore（Beta）、**Privacy 行**（隐私走 About → Privacy Policy）。

## 2. Craft P0 屏幕清单

| ID | 屏幕 | 必含 |
|---|---|---|
| **ON-W** | Welcome（仅首次） | 三词标题（Paste / Connect / Smart）；**无**副文；**无**左上品牌字；**无** no-sell（落在 AS-1 脚）；**无 1·2·3**；Get started |
| **ON-P** | Data & Privacy（仅首次） | 两词（On device / No tracking）；Privacy Policy 外链；Continue；**无**说明卡 / iCloud 句 |
| **H-0e** | Home Empty | 顶栏**仅 Settings**；*Add subscription*；START 弱化 |
| **SUB-1** | Subscriptions | **单列表**：全部订阅；Active 高亮（流量 + 有标签的 Expires/Expired + Update）；非 Active **Set active** 与 Update 同槽（玻璃次按钮，非标题弱字）；底 Add；**Rename = 轻交互**（名旁铅笔 → sheet，非主 CTA）；裸日期禁止；**Connected 时 Set active 先停会话再切**（ADR **0070**）；hi-fi `04-subscriptions.html` · ADR 0033 |
| **AS-1** | Add Subscription | 一句引导；**Paste** 主按钮；Scan QR / File；**无手填框**；无 Found 独立页 |
| **AS-P** | Parsing **模态** | 叠在 AS-1 上（非全屏）；剪贴板 / QR / **File** 共用壳；*Reading from Clipboard…* / *Reading QR code…* / *Reading file…*（与 `en.yaml` / `03-setup` 同源） |
| **AS-1f** | Add 失败态 | *Couldn’t add this* + 去服务商重新复制/扫；Paste again；不列格式名 |
| **H-0** | Home · Idle | Cover Flow；**节点名+弱协议+› 可点→Location**；中部 *Not Connected* + **Mode chip**（Smart/Global ›）；START 顶；无点阵；无中部 Location pill |
| **LOC-1** | Location | 全屏；**扁平全量** · 订阅原序；**无** group chip；行=名·check·协议·ms；点选=Preferred；顶栏 Test（ADR 0055/0056） |
| **H-0s1/s2** | Swipe ⅓ / ⅔ | 1 圈 / 2 圈点亮；节点名锁定；**无** Mode chip |
| **H-1** | Connecting | 3 圈；Connecting…；黑场；**无** Mode chip |
| **H-2** | Connected | 绿场；时长+速率；**节点 glass → Mode 竖叠**；STOP |
| **H-3** | Connect failed | **= H-0 Idle** + 短 toast（*Couldn’t connect. Try again.*）；**无** *Can’t connect* 主状态；**不**自动诊断 sheet（ADR **0059** / **0060**） |
| **ST-0** | Settings 根 | Connection 三行 · App 三行（Auto-update · Subscriptions · About）；**无** History（ADR **0051** / **0015**） |
| **ST-*** | Mode / DNS / Overrides / About | 见 `05-settings.html` · ADR 0031 / 0034 / **0051**；About 含 **MT 披露**；**Privacy** / **Terms** = 外链 `…/privacy/` · `…/terms/`（website/） |

## 3. 主用户流

### 3.1 首次安装（ADR 0019）

```
[ON-W Welcome 仅一次] → [ON-P Data & Privacy 仅一次] → [H-0e Home Empty]
        │ 点 + 或 Add subscription
        ▼
[AS-1 Add Subscription]
   │ 成功 toast + Active          │ 失败：页内原因
   ▼                              ▼
[H-0 Idle]（不自动连）         [AS-1 可重试]
```

### 3.2 连接手势（含首次 VPN 权限）

**无应用内 VPN 说明页。** 首次需配置隧道时，系统直接出 iOS VPN 弹窗。

```
[H-0 Idle] —下滑—▶ [H-0s1] —▶ [H-0s2] —▶ 若尚未授权：iOS 系统 VPN 弹窗
                                              │ 拒绝 → 回 [H-0 Idle]（Swipe down to connect）
                                              │ 同意 → [H-1 Connecting]
                                         │ Probe OK → [H-2 Green / Connection Success]
                                         │ fail → [H-3 = Idle + toast]（MVP 无诊断 UI · ADR 0063）
[H-2] —上滑 STOP—▶ [H-0]
```

已授权后日常路径同 3.2，跳过系统弹窗。

## 4. Home 信息层级

### 4.1 Idle（黑场；失败回退亦同此骨架）

1. 顶栏 glass  
2. **Cover Flow**（国旗圆；浅弧；间距适中）  
3. **节点名 + 弱协议 + 弱 ›**（可点 → Location；可见无 *Location* 词）  
4. **Not Connected**（中部主状态；无 Location pill；**无** *Can’t connect*）  
5. 其下 **Mode** 次级（Smart / Global › → sheet *Mode*；ADR **0058**）  
6. 滑动胶囊 + 手势提示（Swipe down to connect）  
7. 点阵：Idle **无**  
8. **连接失败：** 同 Idle + **短 toast**（约 2–3s · ADR **0059**）；可立即再连  

### 4.1b Swipe（黑场）

同 Idle 上部，但 **节点名行锁定**（无 ›、弱化）；中部仍 *Not Connected*；点阵锚在胶囊底 STOP 位，3 圈内→外。

### 4.2 Connecting（黑场）

1–3 同 Idle 上部（节点名**锁定**）；中部 **Connecting…**；胶囊底 + **3 圈全亮**。

### 4.3 Connected（绿场，整屏连续）

1. 顶栏（浅玻璃，非色块条）  
2. **会话时长** + **↓ / ↑ 本次累计流量**  
3. **Connected**（**无** 状态上方国家/地区名行）  
4. **节点行**（旗 + 节点名 + 弱协议）— **可点 → Location**（绿场进 Location 的唯一主入口；**无** Cover Flow）  
5. 其下 **Mode** 次级文本（Smart / Global ›；**竖叠**，禁与节点横排双 pill）  
6. STOP 胶囊 + 3 圈绿点脉冲  
7. Swipe Up To Stop  

## 5. 双皮肤与手势

| 皮肤 | 触发 | 胶囊 |
|---|---|---|
| Black | 非 Success | START 顶 → 下滑连接 |
| Green | **仅**隧道 + Probe 成功 | STOP 底 → 上滑断开 |

假绿禁止。无应用内 Appearance；光暗跟系统；不可「永远绿皮肤」。

## 6. 诊断 / Repair / Help

**MVP 不做**（ADR **0063**）。Post-MVP 稿：`design/hi-fi/_explore/2026-08-07-help-agent-post-mvp/`。

## 7. 决议映射

| 决议 | UI |
|---|---|
| Connection Success | 仅 H-2 绿场 + Connected |
| Connect Gesture | 三圈点亮过程；Idle 无点 |
| Cover Flow | 节点名非国家名；弱协议 |
| Location | Idle 路径入口，非规则说明 |
| Help / 诊断 | **MVP 无**（0063）；失败 toast（0059） |
| Routing Mode | Home 与 Settings 均为 Smart/Global；Settings 返回时若变更则 `setRoutingMode`（ADR 0058） |
| Connect fail | Idle + toast（ADR 0059）；无 *Can’t connect* |
| 无底 Tab | 顶栏 + sheet |

## 8. 文案锚点（English）

| 场景 | 文案 |
|---|---|
| Idle 主状态 | Not Connected |
| Location | Location |
| 连接中 | Connecting… |
| 成功 | Connected |
| 失败 | *Couldn’t connect. Try again.*（toast；中部仍 Not Connected） |
| Mode chip | Smart / Global |
| 手势 | Swipe down to connect / Swipe up to stop |
| 协议 | **全 app 弱标签短名闭集** `SS` / `VMess` / `VLESS` / `Trojan` / `Hy2`（含 Location 行；**不**写 Hysteria2 全称） |
