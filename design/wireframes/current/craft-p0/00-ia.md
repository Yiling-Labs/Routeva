# Craft P0 — 信息架构与关键流程

> 依据 PRD v0.2 / CONTEXT；**不扩功能**。用户可见文案 **English**。  
> Beta：无付费墙。  
> 视觉方向：**pin glass + vertical capsule**（黑 / 绿双皮肤；**无底部 Tab**）。  
> 权威 hi-fi：Home `02-home.html` · Setup `03-setup.html`  
> 术语：CONTEXT Home Surface / **Home Chrome** / **Subscriptions Surface** / Connect Gesture / **First-Run Setup** · ADR 0018 / **0019** / **0020**  

## 1. 全局导航（无底部 Tab）

**根画布只有 Home。** 顶栏 = **纯出口**（ADR 0020）。诊断 / 修复为 **modal sheet**。

| 面 | 角色 | 进入方式 | Craft |
|---|---|---|---|
| **Home** | 选节点、连接手势、连接真值 | App 根 | P0 Craft |
| **Help (Agent)** | Connection Help；信任条 + 聊天 + 边界；hi-fi `06-agent.html` | 顶栏 **Help** pill | 能力接通 · Craft P1 |
| **Subscriptions** | 单列表 + Active 态；Update / Add | 顶栏左旁（**有订阅时**） | P0 Craft |
| **Settings** | §1.2 闭集；hi-fi `05-settings.html` | 顶栏右 gear | P2 |
| **Activity** | 时间序事件（记录 + 可解释） | **非**顶栏、**非** Settings 根页；Help / 诊断·Repair 上下文（ADR **0051**） | 能力 P0 · 完整列表 Craft P1 |
| **Location Surface** | 分组节点列表、**点选 = Preferred**、Latency Test | Home **Cover Flow 节点名行**（Idle/Can’t）或 **Connected 节点行**（全屏 push） | P0 · ADR **0055** / **0056** |
| **Diagnostic / Repair** | 四桶白话 + Repair Consent；**次要 Ask Help**（ADR 0044） | 失败 sheet | P0 Craft |

### 1.1 顶栏

| 状态 | 布局 |
|---|---|
| **有订阅** | `[ Help ] [ Subscriptions ] ………… [ Settings ]`（Help = glass pill · ADR 0036） |
| **Empty（无订阅）** | `[ Help ] ………… [ Settings ]`（无 Subscriptions；Add 走中部 CTA） |

soft glass 圆钮；**禁止**底 Tab、Go Premium、顶栏常驻 Activity。

### 1.2 Settings Surface（根页闭集）

主职：**Connection Policy 优先**。光暗跟系统；无 Appearance / Advanced / Cloud AI 开关 / 付费墙。

| 段 | 根页行 | 二级要点 |
|---|---|---|
| **Connection** | Routing mode › · DNS › · Overrides › | 每行**释义副文**（解释标题，不绑选项）：Mode *How traffic uses your proxy*；DNS *How names resolve on your connection*；Overrides *Exceptions for specific domains*。二级：Mode Auto/Global/Direct；DNS 三预设；Overrides Domain only（O3；ADR 0045 / **0057** / **0050**） |
| **App** | **Auto-update subscription**（Toggle 默认开）· Subscriptions › · About › | 自动刷新总闸见 ADR **0015**；无根页 Privacy；隐私经 About → Privacy Policy；Subscriptions 深链；Export 在 About 次要 |

**明确不进 Settings 根页：** History/Activity/Snapshots（ADR **0051**）、节点列表、订阅 CRUD 副本、Run Diagnostic 主 CTA、Cloud AI Toggle、Appearance、Advanced、Restore（Beta）、**Privacy 行**（隐私走 About → Privacy Policy）。

## 3. 主用户流

### 3.1 首次安装（ADR 0019）

```
[ON-W Welcome 仅一次] → [H-0e Home Empty]
        │ 点 + 或 Add subscription
        ▼
[AS-1 Add Subscription]
   │ 成功 toast + Active          │ 失败：页内原因
   ▼                              ▼
[H-0 Idle]（不自动连）         [AS-1 可重试]
```

### 3.2 连接手势（含首次 VPN 权限）

**无应用内 VPN 说明页。** 首次需配置隧道时，系统直接出 iOS VPN 弹窗。

```
[H-0 Idle] —下滑—▶ [H-0s1] —▶ [H-0s2] —▶ 若尚未授权：iOS 系统 VPN 弹窗
                                              │ 拒绝 → 回 [H-0 Idle]（Swipe down to connect）
                                              │ 同意 → [H-1 Connecting]
                                         │ Probe OK → [H-2 Green / Connection Success]
                                         │ fail → [H-3]+[D-1]
[H-2] —上滑 STOP—▶ [H-0]
```

已授权后日常路径同 3.2，跳过系统弹窗。

## 4. Home 信息层级

### 4.1 Idle / Can’t connect（黑场）

1. 顶栏 glass  
2. **Cover Flow**（国旗圆；浅弧；间距适中）  
3. **节点名 + 弱协议 + 弱 ›**（可点 → Location；可见无 *Location* 词）  
4. **Not Connected** / Can’t connect（中部**仅**状态；无 Location pill）  
5. 滑动胶囊 + 手势提示（Swipe down to connect）  
6. 点阵：Idle **无**  

### 4.1b Swipe（黑场）

同 Idle 上部，但 **节点名行锁定**（无 ›、弱化）；中部仍 *Not Connected*；点阵锚在胶囊底 STOP 位，3 圈内→外。

### 4.2 Connecting（黑场）

1–3 同 Idle 上部（节点名**锁定**）；中部 **Connecting…**；胶囊底 + **3 圈全亮**。

### 4.3 Connected（绿场，整屏连续）

1. 顶栏（浅玻璃，非色块条）  
2. **会话时长** + **↓ / ↑ Mb/s**  
3. **Connected**（**无** 状态上方国家/地区名行）  
4. **节点行**（旗 + 节点名 + 弱协议）— **可点 → Location**（绿场进 Location 的唯一主入口；**无** Cover Flow；身份只在此呈现一次）  
5. STOP 胶囊 + 3 圈绿点脉冲  
6. Swipe Up To Stop  

## 5. 双皮肤与手势

| 皮肤 | 触发 | 胶囊 |
|---|---|---|
| Black | 非 Success | START 顶 → 下滑连接 |
| Green | **仅**隧道 + Probe 成功 | STOP 底 → 上滑断开 |

假绿禁止。无应用内 Appearance；光暗跟系统；不可「永远绿皮肤」。

## 6. 诊断结果卡（sheet）

权威 hi-fi：`design/hi-fi/current/craft-p0/07-diagnostic.html`  

Bucket（白话：App can fix / Provider / Your network / Not sure）→ Why / Impact / Next → Confidence → 主 CTA Repair（仅可修）或完成类。  
**次要：** *Ask Help* 弱链 → Help 页并带诊断摘要（ADR 0044）。**Not sure** 时主 CTA 可为 Ask Help。禁止第二实心主按钮。叠在 dimmed Home（Can’t connect 黑场）。

## 7. 决议映射

| 决议 | UI |
|---|---|
| Connection Success | 仅 H-2 绿场 + Connected |
| Connect Gesture | 三圈点亮过程；Idle 无点 |
| Cover Flow | 节点名非国家名；弱协议 |
| Location | Idle 路径入口，非规则说明 |
| Diagnostic Trigger | 失败 sheet；成功安静 |
| Routing Mode | Settings；非 Auto 弱提示 |
| 无底 Tab | 顶栏 + sheet |

## 8. 文案锚点（English）

| 场景 | 文案 |
|---|---|
| Idle 主状态 | Not Connected |
| Location | Location |
| 连接中 | Connecting… |

| 失败 | Can’t connect |
