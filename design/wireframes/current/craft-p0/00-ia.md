# Craft P0 — 信息架构与关键流程

> 依据 PRD v0.2 / CONTEXT；**不扩功能**。用户可见文案 **English**。  
> Beta：无付费墙。  
> 视觉方向：**pin glass + vertical capsule**（黑 / 绿双皮肤；**无底部 Tab**）。  
> 权威 hi-fi：Home `02-home.html` · Setup `03-setup.html`  
> 术语：CONTEXT Home Surface / **Home Chrome** / **Subscriptions Surface** / Connect Gesture / **First-Run Setup** · ADR 0018 / **0019** / **0020**  

## 1. 全局导航（无底部 Tab）

**根画布只有 Home。** 顶栏 = **纯出口**（ADR 0020）。诊断 / 修复为 **modal sheet**。

| 面 | 角色 | 进入方式 | Craft |
|---|---|---|---|
| **Home** | 选节点、连接手势、连接真值 | App 根 | P0 Craft |
| **Agent** | NL + 工具 | 顶栏左 | 能力接通 · Craft P1 |
| **Subscriptions** | 单列表 + Active 态；Update / Add | 顶栏左旁（**有订阅时**） | P0 Craft |
| **Settings** | §1.2 闭集；hi-fi `05-settings.html` | 顶栏右 gear | P2（Activity 能力 P0） |
| **Activity** | 时间序事件 | **Settings › History**（非顶栏） | 能力 P0 · Craft P1 |
| **Location / 节点列表** | 换节点、看位置 | Cover Flow 或 **Location ›** | P0 |
| **Diagnostic / Repair** | 四桶 + Repair Consent | 失败 sheet | P0 Craft |

### 1.1 顶栏

| 状态 | 布局 |
|---|---|
| **有订阅** | `[ Agent ] [ Subscriptions ] ………… [ Settings ]` |
| **Empty（无订阅）** | `[ Agent ] ………… [ Settings ]`（无 Subscriptions；Add 走中部 CTA） |

soft glass 圆钮；**禁止**底 Tab、Go Premium、顶栏常驻 Activity。

### 1.2 Settings Surface（根页闭集）

主职：**Connection Policy 优先**。光暗跟系统；无 Appearance / Advanced / Cloud AI 开关 / 付费墙。

| 段 | 根页行 | 二级要点 |
|---|---|---|
| **Connection** | Routing mode › · DNS › · Overrides › | Mode：Auto/Global/Direct + 一行副文；DNS：Automatic/Privacy/Compatibility；Overrides：列表+Add（Service\|Domain → proxy\|direct，≤20） |
| **History** | Activity › · Snapshots › | 事件时间序；快照列表与回滚。Export 不在此段根行 |
| **App** | Privacy › · Subscriptions › · About › | Privacy：本机/不收集/Cloud AI 只读/政策链；Subscriptions 深链；About：版本·链接·Export 次要·不卖节点一句 |

**明确不进 Settings：** 节点列表、订阅 CRUD 副本、Run Diagnostic 主 CTA、Cloud AI Toggle、Appearance、Advanced、Restore（Beta）。

## 3. 主用户流

### 3.1 首次安装（ADR 0019）

```
[ON-W Welcome 仅一次] → [H-0e Home Empty]
        │ 点 + 或 Add subscription
        ▼
[AS-1 Add Subscription]
   │ 成功 toast + Active          │ 失败：页内原因
   ▼                              ▼
[H-0 Idle]（不自动连）         [AS-1 可重试]
```

### 3.2 连接手势（含首次 VPN 权限）

**无应用内 VPN 说明页。** 首次需配置隧道时，系统直接出 iOS VPN 弹窗。

```
[H-0 Idle] —下滑—▶ [H-0s1] —▶ [H-0s2] —▶ 若尚未授权：iOS 系统 VPN 弹窗
                                              │ 拒绝 → 回 [H-0 Idle]（Swipe down to connect）
                                              │ 同意 → [H-1 Connecting]
                                         │ Probe OK → [H-2 Green / Connection Success]
                                         │ fail → [H-3]+[D-1]
[H-2] —上滑 STOP—▶ [H-0]
```

已授权后日常路径同 3.2，跳过系统弹窗。

## 4. Home 信息层级

### 4.1 Idle / Swipe / Can’t connect（黑场）

1. 顶栏 glass  
2. **Cover Flow**（国旗圆；浅弧；间距适中）  
3. **节点名 + 弱协议**（`HKG-01 · VMess`）  
4. **Not Connected** / Can’t connect  
5. **Location ›**（定位图标 + Location + chevron）  
6. 滑动胶囊 + 手势提示（Swipe down to connect）  
7. 点阵：Idle **无**；Swipe 起锚在胶囊底 STOP 位，3 圈内→外  

### 4.2 Connecting（黑场）

1–3 同 Idle 上部；中部 **Connecting…**（无 Location pill）；胶囊底 + **3 圈全亮**。

### 4.3 Connected（绿场，整屏连续）

1. 顶栏（浅玻璃，非色块条）  
2. **会话时长** + **↓ / ↑ Mb/s**  
3. 地区名  
4. **Connected**  
5. 节点名 + 弱协议  
6. STOP 胶囊 + 3 圈绿点脉冲  
7. Swipe Up To Stop  

## 5. 双皮肤与手势

| 皮肤 | 触发 | 胶囊 |
|---|---|---|
| Black | 非 Success | START 顶 → 下滑连接 |
| Green | **仅**隧道 + Probe 成功 | STOP 底 → 上滑断开 |

假绿禁止。无应用内 Appearance；光暗跟系统；不可「永远绿皮肤」。

## 6. 诊断结果卡（sheet，视觉后补）

Bucket → Why / Impact / Next → Confidence → Repair（仅 Client-Fixable）。

## 7. 决议映射

| 决议 | UI |
|---|---|
| Connection Success | 仅 H-2 绿场 + Connected |
| Connect Gesture | 三圈点亮过程；Idle 无点 |
| Cover Flow | 节点名非国家名；弱协议 |
| Location | Idle 路径入口，非规则说明 |
| Diagnostic Trigger | 失败 sheet；成功安静 |
| Routing Mode | Settings；非 Auto 弱提示 |
| 无底 Tab | 顶栏 + sheet |

## 8. 文案锚点（English）

| 场景 | 文案 |
|---|---|
| Idle 主状态 | Not Connected |
| Location | Location |
| 连接中 | Connecting… |
| 成功 | Connected |
| 失败 | Can’t connect |
| 手势 | Swipe down to connect / Swipe up to stop |
| 协议 | 弱化 `· VMess` 等（SS / VMess / VLESS / Trojan / Hy2） |
