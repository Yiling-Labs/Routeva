# Craft P0 — 信息架构与关键流程

> 依据 PRD v0.2 / CONTEXT；**不扩功能**。用户可见文案 **English**。  
> Beta：无付费墙。  
> 视觉方向：**pin glass + vertical capsule**（黑 / 绿双皮肤；**无底部 Tab**）。  
> 权威 hi-fi：`design/hi-fi/current/craft-p0/02-home.html`  
> 术语：CONTEXT **Home Surface / Home Mid Copy / Connect Gesture** · ADR 0018  

## 1. 全局导航（无底部 Tab）

**根画布只有 Home。** Activity / Agent / Settings 从 **顶栏 glass**；诊断 / 修复为 **modal sheet**。

| 面 | 角色 | 进入方式 | Craft |
|---|---|---|---|
| **Home** | 选节点、连接手势、连接真值 | App 根 | P0 Craft |
| **Activity** | 时间序事件 | 顶栏左 | 能力 P0 · Craft P1 |
| **Agent** | NL + 工具 | 顶栏左旁 | 能力接通 · Craft P1 |
| **Settings** | 高级 / DNS / 模式 / 多订阅… | 顶栏右 gear | P2 |
| **Location / 节点列表** | 换节点、看位置 | Cover Flow 或 **Location ›** | P0 |
| **Diagnostic / Repair** | 四桶 + Repair Consent | 失败 sheet | P0 Craft |

### 1.1 顶栏

`[ Activity ] [ Agent ] ………… [ Settings ]` — soft glass 圆钮；**禁止**底 Tab、Go Premium。

## 3. 主用户流（连接）

```
[H-0 Idle] —下滑—▶ [H-0s1 1圈] —▶ [H-0s2 2圈] —▶ [H-1 Connecting 3圈]
                                              │ success Probe
                                              ▼
                                         [H-2 Connected · Green]
                                              │ 上滑 STOP
                                              ▼
                                         [H-0 Idle]
失败 Probe → [H-3] + [D-1 sheet] → Client-Fixable 则 Repair 闭环 → 成功回 H-2
```

## 4. Home 信息层级

### 4.1 Idle / Swipe / Can’t connect（黑场）

1. 顶栏 glass  
2. **Cover Flow**（国旗圆；浅弧；间距适中）  
3. **节点名 + 弱协议**（`HKG-01 · VMess`）  
4. **Not Connected** / Can’t connect  
5. **Location ›**（定位图标 + Location + chevron）  
6. 滑动胶囊 + 手势提示（Swipe Down To Connect）  
7. 点阵：Idle **无**；Swipe 起锚在胶囊底 STOP 位，3 圈内→外  

### 4.2 Connecting（黑场）

1–3 同 Idle 上部；中部 **Connecting…**（无 Location pill）；胶囊底 + **3 圈全亮**。

### 4.3 Connected（绿场，整屏连续）

1. 顶栏（浅玻璃，非色块条）  
2. **会话时长** + **↓ / ↑ Mb/s**  
3. 地区名  
4. **Connected**  
5. 节点名 + 弱协议  
6. STOP 胶囊 + 3 圈绿点脉冲  
7. Swipe Up To Stop  

## 5. 双皮肤与手势

| 皮肤 | 触发 | 胶囊 |
|---|---|---|
| Black | 非 Success | START 顶 → 下滑连接 |
| Green | **仅**隧道 + Probe 成功 | STOP 底 → 上滑断开 |

假绿禁止。Appearance 不可「永远绿皮肤」。

## 6. 诊断结果卡（sheet，视觉后补）

Bucket → Why / Impact / Next → Confidence → Repair（仅 Client-Fixable）。

## 7. 决议映射

| 决议 | UI |
|---|---|
| Connection Success | 仅 H-2 绿场 + Connected |
| Connect Gesture | 三圈点亮过程；Idle 无点 |
| Cover Flow | 节点名非国家名；弱协议 |
| Location | Idle 路径入口，非规则说明 |
| Diagnostic Trigger | 失败 sheet；成功安静 |
| Routing Mode | Settings；非 Auto 弱提示 |
| 无底 Tab | 顶栏 + sheet |

## 8. 文案锚点（English）

| 场景 | 文案 |
|---|---|
| Idle 主状态 | Not Connected |
| Location | Location |
| 连接中 | Connecting… |
| 成功 | Connected |
| 失败 | Can’t connect |
| 手势 | Swipe Down To Connect / Swipe Up To Stop |
| 协议 | 弱化 `· VMess` 等（SS / VMess / VLESS / Trojan / Hy2） |
