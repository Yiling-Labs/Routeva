# docs/ — Agent 原则

## 职责

文字侧：**guides（L2）**、**prd 骨架（L1）**、**sessions 过程**、**adr 决策**。

## 子目录

| 路径 | 层 | 用途 |
|---|---|---|
| `guides/` | L2 | 品类基础实践与清单（init 按 type 生成） |
| `prd/` | L1→L3 | PRD 规划与空壳；业务正文后续写 |
| `sessions/` | 过程 | grill、Brief 原料 |
| `adr/` | 决策 | 难逆结构/流程 |

## 权威（有正文之后）

- 产品摘要字段 → `PRODUCT.md` 内容区  
- 深规格 → `prd/PRD.md`  
- 过程稿需晋升后才算数  
- 品类「应该备齐什么」→ `guides/`（不是本产品功能）  

## 原则

1. 过程稿落 `sessions/`，收敛后晋升。  
2. 不在 `docs/` 放设计二进制或商店截图。  
3. 不在 guides 里写本产品功能列表。  
4. 本文件只约束文档结构。
