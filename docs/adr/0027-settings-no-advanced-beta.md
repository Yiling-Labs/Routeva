# Beta Settings 不露 Advanced 入口

Beta 正式 **Settings Surface** 不提供 Advanced / 高级模式段或隐藏连点入口。根页仅 Connection / History / App 已定闭集。Export 等残留作已有面的次要动作；内核、日志级别、实验协议 **无** 用户向入口（开发构建另议）。

**为何：** Mode/DNS/Override/Activity/Snapshots 已抬成主路径；再挂 Advanced 易成双轨坟场，与普通用户定位冲突。隐藏手势可日后加，非 Beta 门槛。

**后果：** PRD「高级模式完整清单」降为 P2/商业化后议题；见 CONTEXT **Settings Surface**。
