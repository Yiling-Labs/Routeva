# Beta Settings 不露 Advanced 入口

Beta 正式 **Settings Surface** 不提供 Advanced / 高级模式段或隐藏连点入口。根页闭集（ADR **0051**）：**Connection → App**（无 History）。Export 等残留作已有面的次要动作；内核、日志级别、实验协议 **无** 用户向入口（开发构建另议）。

**为何：** Mode / DNS / Override 已在 Connection 主路径；About / 隐私外链在 App。再挂 Advanced 易成双轨坟场，与普通用户定位冲突。Activity / Snapshots **不**靠 Advanced 或 Settings 列表补回（触点在 Help / Repair · 0051）。隐藏调试手势可日后加，非 Beta 门槛。

**后果：** PRD「深层调试入口」降为 P2/商业化后议题；见 CONTEXT **Settings Surface**。
