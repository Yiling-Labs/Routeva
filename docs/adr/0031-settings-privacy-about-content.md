# Privacy / About 内容闭集（P-A + O-A）

**Privacy ›：** 本机数据说明、默认不收集短列表、Cloud AI 只读说明（无开关）、分析明示或诚实无 SDK、外链 Privacy Policy。不做 App 内嵌长法务全文、不做 Cloud AI 第二 Toggle。

**About ›：** 产品名+版本、政策/条款/支持链接、次要 **Export diagnostic report**（脱敏）、一句不卖节点。无连点 Advanced；Beta 不强制 Rate/Share。清除全部本机数据等危险操作另议。

**为何：** VPN/代理品类需要可扫的信任说明，但 Settings 不是法务站；Export 落 About 次要动作补齐 History 不占根行的缺口。

**后果：** 见 CONTEXT **Settings Surface** App 条。
