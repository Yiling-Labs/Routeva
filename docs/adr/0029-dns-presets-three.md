# DNS：三档意图预设，非品牌列表

客户端 DNS 为单选闭集：**Automatic**（默认）· **Privacy** · **Compatibility**。UI 按意图命名，不陈列 Cloudflare/Google 等品牌清单；具体解析器为实现常数。禁止 MVP 自定义 DNS 表单。Repair Allowlist 的 DNS 切换与 Settings 同一闭集。

**为何：** 目标用户要的是「自动 / 更隐私 / 更兼容」，不是解析器选秀；品牌列表增合规与杂讯。Settings 与 Repair 同源避免神秘第四档。

**后果：** 见 CONTEXT **Settings Surface** Connection/DNS；文案 English 源可再打磨。
