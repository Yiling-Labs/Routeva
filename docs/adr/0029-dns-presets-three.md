# DNS：运行时固定 Automatic

**修订：** Settings **不再**暴露 DNS 选择器。连接编译一律 **Automatic**（直连域名 = 系统解析器；走当前节点的名字经节点解析）。禁止自定义 DNS 表单。Privacy / Compatibility 不再作为用户可选档。

**为何：** 目标用户要的是「自动 / 更隐私 / 更兼容」，不是解析器选秀；品牌列表增合规与杂讯。Settings 与 Repair 同源避免神秘第四档。

**后果：** 见 CONTEXT **Settings Surface** Connection/DNS；文案 English 源可再打磨。
