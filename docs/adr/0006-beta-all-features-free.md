# Beta 阶段功能全免，收费后置规划

在 Beta（含封闭/公开测试，直至宣布进入商业化）期间，MVP 范围内能力**默认全部可用、不限额、不展示付费墙**。先前 ADR 0001 与 CONTEXT 中的 Free Experience / Pro Unlock / $2.99 数字视为**目标商业模型草稿**，供日后规划收费项目时沿用或改写；**不作为 Beta 出门或验收门槛**。商业化时机、价格与配额在 Beta 验证主证明点（Self-Healing Loop + 连接稳定性）之后另开决策，不在本轮扩品类。

**Considered Options**
- Beta 即按 3 次诊断 / 1 次 Repair 等硬配额 → 污染诊断与稳定性样本，客服与差评成本高。
- Beta 全免且文档删除 Free/Pro → 日后重写商业叙事成本高。
- **选定（D）：** Beta 产品行为全免；文档保留目标商业草稿；收费项目后期再规划。
