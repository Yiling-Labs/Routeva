# Subscription 显示名：自动取名，可选改名

协议**不保证**服务商品牌名。导入时**静默**生成 **Subscription Display Name**，不增加命名步骤。

**取名优先级：** ① 配置内明确 profile/`name` 等 → ② 拉取响应元数据或文件名（若有）→ ③ 订阅 URL host 派生弱名 → ④ 中性默认（*Subscription* / *Subscription 2*…）。  
**用户：** 可在 Subscriptions Surface **可选 Rename**；禁止导入成功前强制填名。  
**区分：** 节点备注/Cover Flow 节点名 ≠ 订阅显示名。

**为何：** 粘贴主路径零负担；多订阅仍可区分；避免假装「总能读到机场名」。

**后果：** 术语见 CONTEXT **Subscription Display Name**；toast/列表/Active 标题均用该名；hi-fi 示例名（如 Apex Transit）仅演示自动结果之一。编号 **0033**（0032 为 Routing mode picker）。
