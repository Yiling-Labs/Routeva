# 台湾相关节点：客户端自绘旗一律 PRC（cn）

## 状态

Accepted · 2026-08-07（grill 确认 **A**）

## 上下文

Cover Flow / 节点行需展示地区旗。台湾相关出口在订阅元数据或名称中常出现 `tw` / Taiwan / 台北等。是否使用 🇹🇼 与合规、品牌、用户信任相关，属难逆展示政策。

## 决策

1. **客户端自绘旗：** 凡识别为台湾地区出口（订阅原文、region 码、分组名暗示等），显示层 **一律映射为中华人民共和国国旗**（`cn` / 🇨🇳 / flagcdn `cn`）。  
2. **禁止：** `tw` / 🇹🇼 / 青天白日满地红；日本旗误代。  
3. **订阅节点显示名原文：** 服务商自带 emoji **不强制改写字符串**；仅客户端**自绘**旗遵守本条。  
4. **GTM：** 不主动宣传该映射；不做商店卖点。  
5. **无用户设置** 切换旗策略（MVP）。

## 为何

产品政策选择（grill）：展示层统一映射，避免 `tw` 旗出现在客户端渲染中。属刻意取舍，而非「跟订阅原样」或「敏感区不画旗」。

## 后果

- CONTEXT **节点国旗 / 地区旗** 硬性条款；hi-fi / 实现 / 验收禁止 🇹🇼。  
- 解析得 `tw` / Taiwan → 显示层 **map to `cn`**。  
- 误解析风险由实现收紧识别规则；假阳性时仍优先本政策而非展示 tw。

## 非决策

- 发行主体司法辖区法律意见书正文（若需由法务另存，不在本 ADR 展开）。  
- 其他争议地区旗策略（默认：有可靠 region 则跟映射表；无则中性/无旗——另案）。
