# Agent Surface 骨架：信任条 + 聊天 + 边界入口

Agent 页定为：**顶信任条**（点进 How we use data）+ **中对话/空态与快捷问题** + **What Help can do ›** 边界 + **底输入**。不做首次强制信任 onboarding 后纯聊天，不做三栏，不把信任/边界只塞进菜单。

**为何：** Connection Help 须同时可聊与可建立隐私/能力信任；常驻可扫信任条 + 可回看边界，优于一次性墙或完全隐藏。

**后果：** 见 CONTEXT **Agent Surface**；信任条文案主张与 Can/Can’t 闭集另议。
