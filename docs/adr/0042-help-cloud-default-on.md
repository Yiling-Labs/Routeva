# Help 内 Cloud assist 默认开，无授权 sheet

Agent Surface（Help）中云端增强 **默认开启**，**不**使用首次授权 modal sheet。披露依赖常驻信任条（*Temporary analysis only · not stored after help*）与 *How we use data*；用户可一键关闭并回本机路径。Settings **仍无** Cloud 开关。

**为何：** 目标用户多在本国网络不畅时求助，授权墙摩擦过高；常驻条 + 可关 + Ephemeral structured context 承担诚实披露。代价：从严格 Opt-in 改为 Help 内 **opt-out**；About/隐私文案不得再写绝对 never upload。

**后果：** 修订 CONTEXT **Cloud AI**；部分取代 ADR 0025 的「首次同意」条款；hi-fi 默认 Cloud On 条。
