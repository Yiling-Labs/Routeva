# 订阅更新：前台按需，禁止固定后台轮询

Active Subscription 仅在用户冷启动 App 或发起连接、且距上次成功更新超过间隔 T（默认 6h）时尝试自动刷新。禁止固定后台周期拉取订阅（耗电、体验差、iOS 后台不可靠）。更新成功安静落盘并记 Activity；失败不覆盖已有可用配置。用户可手动更新；Repair 中的重载订阅仍保留在失败路径。

**Considered Options**
- 固定后台周期刷新 → 耗电与不可靠，明确不做。
- 仅手动更新 → 节点列表易陈旧，削弱 Table Stakes。
- **选定：** 前台/连接前按 T 刷新 Active；少打扰；失败不覆盖。
