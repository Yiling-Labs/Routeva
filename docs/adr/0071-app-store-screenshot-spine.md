# App Store 截图走 Crafted Connect 脊柱与三车道探索

商店 listing 截图与官网共用 **Crafted Connect**，但首图卖 **Connection Success**。闭集 **四** 张 Spine：Connected → Idle 手势 → Add Subscription → Location。**无** Connecting 收束张。禁止抄竞品的 MitM、Clash、OTT 解锁、协议墙。

**选定：** **A · Jobs**（2026-08-14 晋升）。HTML 视觉源 `design/hi-fi/current/store-screenshots/`。渠道成品 `gtm/stores/app_store/screenshots/<locale>/`（ADR **0072** 八语）。上架前产品 UI 须与二进制一致。

**Status:** accepted · 2026-08-14  
**Relates:** ADR **0067** · **0063** · CONTEXT Store Screenshot Set / Spine

## Considered Options

- 3 张只保前三屏：丢掉 Location 与 Probe 收束  
- 首图卖「不卖节点」或功能清单：官网已否定，竞品也已占满「工具台」车道  
- 抄 Stash/QX 的 MitM · Clash · 流媒体解锁：与产品非目标冲突  

## Consequences

- 不把 Connecting 过程态当作 listing 收束张  
- GTM 演示节点不用台湾出口（不宣传旗映射）  
- 流量数字用本次连接累计，不用 Mb/s  
- listing 视觉源只读 `design/hi-fi/current/store-screenshots/`；渠道 PNG 只写 `gtm/stores/app_store/screenshots/<locale>/`；不从 `_explore/` 导出  
- 八语标题见 session 2026-08-14；en 金句不改
