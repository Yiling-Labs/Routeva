# Settings 根页不设 Privacy 行

Settings 根页 **App** 段去掉 **Privacy ›**，仅保留 **Subscriptions ›** 与 **About ›**。应用内隐私说明经 **About → Privacy Policy** 进入（或外链完整政策），不与根页并列第二入口。

**为何：** 根页 Privacy 与 About 内 Privacy Policy 职责重叠，增加扫描成本；About 品牌卡已承载隐私承诺一句。

**后果：** 修订 ADR 0026 / 0031；CONTEXT **Settings Surface** App 条；hi-fi `05-settings.html`。（编号 0034：0033 已用于 subscription display name。）
