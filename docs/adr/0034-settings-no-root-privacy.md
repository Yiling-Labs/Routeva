# Settings 根页不设 Privacy 行

Settings 根页 **App** 段去掉 **Privacy ›**，仅保留 **Subscriptions ›** 与 **About ›**。完整政策经 **About → Privacy Policy → 系统浏览器** 打开 **`https://routeva.yilinglabs.com/privacy/`**，不与根页并列第二入口。

**为何：** 根页 Privacy 与 About 内政策职责重叠；Web 单一权威源；About 品牌卡承载一句隐私承诺。

**后果：** 修订 ADR 0026 / 0031；CONTEXT **Settings Surface** App 条；hi-fi `05-settings.html`。（编号 0034：0033 已用于 subscription display name。）
