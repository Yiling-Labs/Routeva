# Home 顶栏：Agent · Subscriptions · Settings（Activity 降级）

Home 顶栏定为**纯离开根画布的出口**，不做状态徽章或一键动作捷径。

**常驻出口（有订阅时）：** `[ Agent ] [ Subscriptions ] …… [ Settings ]`。  
**无订阅（Home Empty）：** 隐藏 Subscriptions，仅为 `[ Agent ] …… [ Settings ]`；添加只走中部 *Add subscription*（与 Add 流同一套）。

**Subscriptions：** 一级面 **单列表**（全部订阅 + Active 态区分；Active 行可 Update / 有则显示流量到期；非 Active 可 Set active；底 Add）。**无**独立 All 第二层。订阅管理 **单门 UI**；Settings 可深链，不复制。

**Activity：** 仍为能力 P0（可查事件），但**不进顶栏**——放 Settings 二级（Agent 可摘要）。理由：用户很少以「看日志」为日常任务；顶栏位让给订阅资产与 Agent。

**为何：** 与「连接真值在中部、配置/资产/助手在出口」一致；砍掉难解释的 Activity 一级入口；把多订阅与到期/流量从 Settings 深处拉到可发现入口。

**后果：** 取代「顶栏 Activity · Agent · Settings」旧 IA。术语见 CONTEXT **Home Chrome / Subscriptions Surface / Activity Log**；IA 见 `00-ia`；Subscriptions hi-fi 见 `design/hi-fi/current/craft-p0/04-subscriptions.html`。
