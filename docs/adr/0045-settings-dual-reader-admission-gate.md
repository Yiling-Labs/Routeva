# Settings：双读者 C2 + 准入闸门

产品要覆盖小白与半专业（人群 C），但 **Settings Surface 不实现为双主 IA**。采用 **C2**：同一套短策略闭集；**半专业为主读者**（主动改意图）；小白为被引导的次要读者（默认 + 短副文 + 失败/Help 引进同一页）。扩大人群靠 Table Stakes Connect + Self-Healing + Help，**不**靠设置密度或 Shadowrocket 对标。

**Connection 三项维持根页可发现：** Routing mode 三选一；DNS 意图三档预设；Overrides 常驻但 **O3 呈现**（空态/副文防「完整规则引擎」误读）。有价值的「专业」= 可审计策略意图；无价值 = 内核旋钮、自定义 DNS 表单、正则/规则市场、Advanced 坟场。

**O3 English 源（hi-fi `05-settings.html`）：** 空态 *No exceptions yet* + *a few exceptions, not a full rule set*；列表顶同旨提示；CTA / sheet 标题 *Add exception*；sheet 副文禁 regex/通配；根页计数 `None` / `N`（不写 *rules*）。

**Settings Admission Gate（新项默认全过）：** ① 改流量/连接策略意图；② 半专业会主动改；③ 小白失败/Help 可一句话进同一页；④ 短闭集 + 意图文案；⑤ 与 Home/Repair/Help 同源。**例外：** Activity / Snapshots / About 走可解释性·信任·合规闸门。

**拒绝：** 根页简单/高级双模式；竞品设置清单当 backlog；为「更小白」删掉 Mode/DNS/Override 可发现入口导致 Repair 状态黑盒。

**后果：** 见 CONTEXT **Settings Surface**、**Settings Admission Gate**；与 ADR 0021 / 0023 / 0027 / 0029 / 0032 一致并补读者与准入标准。
