# Home 顶栏：Help glass pill

Home 进入 Agent Surface 的控件定为用户可见 **Help** 的 **soft glass pill**（助手向图标 + *Help* 字样），不再用与 Settings 同质的纯抽象圆标。内部/代码可仍称 Agent。布局：`[ Help ] [ Subscriptions? ] …… [ Settings ]`。无红点、无强迫动效；诊断卡可有次要 Ask Help，不取代顶栏。

**为何：** Connection Help 主职（ADR 0035）需要可扫语义；*Agent* 对目标用户不友好；仅换图标仍偏弱。

**后果：** 见 CONTEXT **Home Chrome** / **Home Surface**；改 `02-home` / Empty 顶栏与 a11y label。
