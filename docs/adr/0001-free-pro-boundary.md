# 免费体验完整首次成功，Pro 售卖长期自愈自动化

> **Status：** 目标商业模型草稿。Beta 行为以 [0006-beta-all-features-free](./0006-beta-all-features-free.md) 为准（功能全免）；商业化开启后可沿用或改写本 ADR。

MVP 目标商业模式定为一次性永久解锁。免费档须让用户完成「导入 → 连上 → 有限次诊断」，以验证兼容与 Table Stakes Connect，并尝鲜 Self-Healing Loop；Pro 售卖不限诊断、一键修复、自动选节点/故障切换、Agent、分流与提醒等长期自动化。转化优先限制自动化与诊断次数，而非默认硬切断 VPN；付费墙不在首次启动出现，而在用户已真实连上之后的高价值动作处触发。

**Considered Options**
- 免费几乎不能日常连接 → 转化可能高，但用户验证不了兼容，也体验不到诊断价值。
- 免费含完整自动修复 → 易出现长期白嫖，削弱 $2.99 付费理由。
- **选定（目标模型）：** 免费给足首次成功与有限诊断；Pro 买「不用再管」。

**配额草稿（Q10，按本机安装；Beta 不生效）：** 诊断 3 次；Repair 1 次；含首次自动选节点连接；不含后台自动故障切换。Agent 共享诊断池，Repair 单独计数。
