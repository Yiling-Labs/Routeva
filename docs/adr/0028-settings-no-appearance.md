# Settings 无 Appearance；光暗跟随系统

Beta **Settings 不提供 Appearance / 主题** 入口。UI Light/Dark **仅跟随 iOS 系统**。连接 **绿场仍仅 Connection Success（含 Probe）**，禁止用主题做成「永远绿」或品牌皮肤包。

**为何：** 产品视觉真值在连接态而非换肤；多一套 Appearance 对目标用户价值低，还易与双皮肤语义打架。系统设置已覆盖光暗与多数显示辅助。

**后果：** App 段为 Privacy · Subscriptions · About 三行（修订 0026）；hi-fi 须同时适配系统 Light/Dark，无应用内主题开关。
