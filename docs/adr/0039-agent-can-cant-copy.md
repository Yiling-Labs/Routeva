# What Help can do：4+4 意图句闭集

Agent 边界展示固定为 **Help can** 四条 + **Help can’t** 四条（English 源见 CONTEXT **Agent Surface**），不镜像全部工具、不只列 Can’t、不写 and more。须与 Diagnostic Engine、Repair Consent、Tool Allowlist、Ephemeral Analysis Context 一致。

**为何：** 普通用户可扫；防止边界文案宽于实现或缩成纯恐吓。

**后果：** hi-fi / 实现以 CONTEXT 条文为准；增删条须改文档。
