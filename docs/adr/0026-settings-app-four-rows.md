# Settings · App 段（Beta）

Settings 根页 **App** 段现为两行：**Subscriptions ›**（深链）、**About ›**（**0028** 去 Appearance；**0034** 去根页 Privacy）。Beta **不**放 Restore Purchases、付费墙、账号。

**为何：** Empty 时顶栏无 Subscriptions，Settings 深链保证管理入口对称；About 收纳版本与隐私入口，避免与 Privacy Policy 双入口。Restore 在无 IAP 的 Beta 易成死行，商业化再加。

**后果：** 见 CONTEXT **Settings Surface** App 条与 ADR 0028 / 0034。
