# First-Run Setup 极简路径

首次安装流程定为：**Welcome（仅一次）→ Home Empty → Add Subscription**（用户主动点 + / Add）。砍掉欢迎页 1·2·3 卡片墙与「导入成功立刻要 VPN」连环步。

**Add Subscription：** 以 **Paste from Clipboard** 为主，辅以 Scan QR / Import file；**无手填框**、**无**「剪贴板已发现」独立页。Paste/扫码后统一 **Parsing 模态**（叠在 Add Subscription 上，非独立全屏）。成功：直接回 **与 Home 同壳的 Idle** + 轻 toast（**2–3s 自动消失**）、设 Active、不自动连。失败：短句引导重新从服务商复制/扫码，不列格式清单；不覆盖已有配置。

**VPN 权限：** **无** 应用内 VPN 说明页。首次真正连接手势时直接出 **iOS 系统 VPN 弹窗**。拒绝 → Home 回到 Idle（*Swipe down to connect*）；同意 → 走连接流程，达 Connection Success 则进 Connected。不绑在导入成功瞬间。

**为何：** 与「降低负担」一致；真实用户只会粘贴/扫码；导入≠已连接；系统弹窗已足够，自建页重复且添负担。

**后果：** 取代偏重的 Welcome+Import+VPN 连环稿；hi-fi 以 `03-setup.html` 为准（至 Home Idle + toast，**无** VPN 自建屏）；术语见 CONTEXT **First-Run Setup / Add Subscription**。
