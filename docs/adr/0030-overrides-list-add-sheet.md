# Overrides：列表 + Add sheet（Service 或 Domain）

Settings **Overrides ›** 为规则列表 + Add sheet：目标 = 预设 **Service** 或单个 **Domain**；动作 = **proxy | direct**；每条可开关/删除；≤20。非文本速记、非仅 Agent 可写、非「只预设服务不可域名」。

**为何：** 对齐结构化 User Override，服务预设降常见路径摩擦，单域名覆盖长尾；避免迷你规则编辑器。与 Agent 同一模型。

**后果：** 见 CONTEXT **User Override Rule**；Service 预设名单与空态文案实现/设计期定。
