# 诊断 sheet 次要入口 Ask Help

连接失败时的 **Diagnostic sheet** 在主 CTA（Repair / 完成类）之外，增加弱入口 **Ask Help**（文字链或 ghost），进入 Agent Surface / Help，并携带本次诊断结构化摘要。顶栏 Help pill 仍为常驻出口；sheet 不自动跳全屏 Help，不设第二实心主按钮。

**为何：** 失败当下视线在 sheet；次要入口降低「还要自己找顶栏」的成本，同时保留 Self-Healing 主路径（先看懂 → 确认修复）。

**后果：** 见 CONTEXT **Home Chrome**；诊断 hi-fi 必含此控件；与 ADR 0035/0036 互补。
