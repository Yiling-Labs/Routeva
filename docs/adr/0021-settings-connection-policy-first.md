# Settings 根页：Connection Policy 优先

Settings Surface 根页主职定为 **Connection Policy 优先**（Routing Mode / DNS / User Override 等改走流量策略的项置顶），而非 Trust/History 占满第一屏，也非「仅 2–4 项 + 其余全进 Advanced」。

**为何：** Home 已扛连接真值与手势；Settings 承接低频策略变更。Activity 须可解释（能力 P0）但**不是**日常任务——**0051** 后不占 Settings 根页，触点在 Help / 失败路径。Trust-first 会把 Settings 做成运维台；过狠 Advanced 会藏掉 DNS/Override，与 Repair Allowlist 叙事冲突。

**后果：** 根部分组与行级闭集、Snapshot/Advanced 曝光另议；术语见 CONTEXT **Settings Surface**。
