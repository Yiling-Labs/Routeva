# Security policy

Please do not disclose suspected vulnerabilities, credential exposure, or
privacy issues in a public issue.

Use GitHub's private vulnerability reporting for
[Yiling-Labs/Routeva](https://github.com/Yiling-Labs/Routeva/security/advisories/new).
Include the affected commit, reproduction steps, impact, and only synthetic
test configuration. Never include a real subscription URL, node credential,
private key, certificate, or provisioning profile.

The maintainers will acknowledge a report as capacity permits, investigate it,
and coordinate disclosure after a fix is available. This document does not
promise a specific response or support SLA.
