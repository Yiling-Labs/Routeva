## Value proposition

Routeva is a smart **proxy client** for people who already have a proxy subscription: **connect without the maze**—paste to a real connectivity check—without selling nodes.

## Core pains

1. Proxy clients bury users in configuration and technical error codes.
2. Failures don’t make clear whether the client, subscription, or user is at fault.

## Benefit bullets

1. Paste subscription → connect with a crafted path
2. Connectivity Probe verifies access
3. Less protocol anxiety for everyday overseas apps

## Feature bullets

1. Table Stakes Connect (import, test, VPN, probe)
2. Auto Policy (Smart) + location / latency
3. Craft connect UI + subscriptions & settings
