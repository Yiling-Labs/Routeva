## Value proposition

Routeva is a smart **proxy client** for people who already have a proxy subscription: **connect without the maze**—paste to a real connectivity check—without selling nodes.

## Core pains (1–2)

1. Existing proxy clients bury users in configuration and technical error codes.
2. When connection fails, users don’t know if it’s the client, the subscription, or them—and end up in airport support or tutorials.

## Benefit bullets

1. Paste subscription → connect with a considered, craft path
2. Connectivity Probe verifies access—not a fake “connected” state
3. Less protocol/routing anxiety for everyday overseas apps

## Feature bullets

1. Table Stakes Connect (import, test nodes, VPN, probe)
2. Auto Policy (Smart) + location / latency pick
3. Craft connect UI (clear states, calm glass chrome)
4. Subscriptions & settings without power-user maze
