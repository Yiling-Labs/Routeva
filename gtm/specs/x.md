# X（Twitter）— 素材与文案速查

> last_reviewed: 2026-08-05  
> 平台 UI 常变，**以 X 官方帮助中心为准**。

## 文本

| 类型 | 常见限制 | 建议 |
|---|---|---|
| 单条帖文 | 免费账号约 **280** 字符；付费更高 | 首句给钩子；链接可单独一条或线程末条 |
| 线程 | 多条串联 | 1 条问题/结果，2–n 条证明，末条 CTA |

## 图片 / 视频（常见）

| 资产 | 建议 | 说明 |
|---|---|---|
| 单图 | **1600×900**（16:9）或 **1080×1080** | 关键信息避开边缘裁切 |
| 多图 | 每张尽量同比例 | 最多张数以客户端为准 |
| 视频 | 常见横版 16:9；短视频可用竖版 | 控制时长与字幕；音量友好 |

## 内容原则

- 演示 > 口号；尽量用真实 UI 或 3 秒内看懂的价值
- 避免纯硬广连发；配合产品更新日志更自然
