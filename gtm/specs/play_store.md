# Google Play — 素材与文案速查

> last_reviewed: 2026-08-05  
> **以 [Play Console 图形资源规范](https://support.google.com/googleplay/android-developer) 为准**。

## 图形

| 资产 | 尺寸 | 说明 |
|---|---|---|
| High-res icon | **512×512** | 32 位 PNG |
| Feature graphic | **1024×500** | 商店页顶图 |
| Phone screenshots | 最少 2 张；边长 **320–3840** px | 建议 16:9 或 9:16 统一 |
| Tablet screenshots | 按需 | 若声明平板支持 |

## 文案（常见上限）

| 字段 | 限制（量级） |
|---|---|
| Title | 30 字符 |
| Short description | 80 字符 |
| Full description | 4000 字符 |

## 视频

- 可使用 YouTube URL；预告片规范见 Play 文档
- 本地成片仍建议纳入 `gtm/video/` 管理

## 目录约定

`gtm/stores/play_store/`
