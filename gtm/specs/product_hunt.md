# Product Hunt — 素材与文案速查

> last_reviewed: 2026-08-05  
> 最佳实践速查，**以 Product Hunt 官方 / 当前提交表单为准**。  
> 建议核对周期：每季度或每次上架前。模板维护方：LYSkills `init_project`。

## 图片（常见）

| 资产 | 建议尺寸 | 说明 |
|---|---|---|
| Thumbnail / Logo | **240×240** px | 正方形，产品识别 |
| Gallery images | **1270×760** px | 横版画廊；保持同一套视觉语言 |
| GIF（若用） | 控制体积与时长 | 优先清晰演示核心价值 |

## 文案（常见上限，提交前以表单为准）

| 字段 | 常见限制 | 建议 |
|---|---|---|
| Name | 短名称 | 与品牌一致 |
| Tagline | 约 **60** 字符量级 | 结果导向，避免空洞形容词堆砌 |
| Description | 较长正文 | 问题 → 方案 → 给谁用 → 差异点 |
| Topics | 平台可选 | 选最相关，勿堆砌 |
