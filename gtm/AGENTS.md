# gtm/ — Agent 原则

## 职责

Go-to-market：应用商店与发布阵地素材、社媒宣发、宣传视频，以及**渠道尺寸/文案限制速查**。

## 子目录

| 路径 | 用途 |
|---|---|
| `specs/` | 各渠道最佳实践速查（尺寸、字数等）；官方文档优先 |
| `stores/` | 各商店/PH 的上架素材与文案 |
| `social/` | X、Reddit 等宣发 |
| `video/` | 宣传视频及相关脚本/封面 |

## 原则

1. **先查 `specs/` 再制作素材**，避免尺寸返工。
2. 只为本产品已启用的渠道保留 store 目录；不要随手新建未约定的顶层渠道名。
3. 文案与图片按渠道路径存放，命名带渠道与用途（如 `cws-screenshot-01.png`）。
4. 不在此存放应用源码或 PRD 正文。
5. 渠道限制会变：修改 specs 时注明核对日期；以官方为准。
